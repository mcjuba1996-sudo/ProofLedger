# ProofLedger Live 0.6.0

- Судья может скачать образец, загрузить один UTF-8 файл Python, выбрать агента и пройти полный эпизод в браузере.
- На каждый запуск создаётся отдельный экземпляр CPython WASI. Ему доступны публичные наблюдения, канал действий и стандартная библиотека для чтения. Оценку выполняет основной процесс.
- Добавлены три загружаемых примера для проверки пустого отчёта, поиска дублей счетов и сверки распределения платежей. Имя и идентификатор выбранного агента сохраняются в экспортируемом отчёте и траектории.
- В комплект для Windows x64 вошли интерпретатор WASI и движок Wasmtime. Подробности запуска и контракта агента приведены в README.

# ProofLedger Live 0.5.0

## Интерфейс и исполнение

- Локальный веб-интерфейс на русском языке с изометрической схемой аудита.
- Запуск встроенного Reconciler через отдельный процесс и JSON-протокол.
- Реальные события reset/step, журнал, просмотр запросов и наблюдений.
- Воспроизведение траектории с управлением скоростью отдельно от измеряемого времени агента.
- Итоговые P/R/F1, TP/FP/FN, награда, время, экспорт JSON и JSONL.
- Режимы demo/closed, ограниченный локальный API и остановка запуска.
- Все ресурсы интерфейса локальные; внешние библиотеки для работы приложения не нужны.
- Windows-запуск через START.cmd; универсальная команда python -m proofledger.live.

## Исправления ядра

- Неверные типы table и currency обрабатываются по контракту без TypeError.
- Контроль бюджета не допускает выполнение шага 101.
- RPC-сервер отклоняет JSON-массивы и null без аварийного завершения.
- Decimal-нормализация калькулятора использует явно заданную точность.
- Число контрагентов проверяется до подбора уникальных названий.
- Остаточное округление последней части платежа описано в публичной policy.
- Добавлены регрессионные и интеграционные проверки.

## Граница этой версии

Подключён собственный Reconciler. Загрузки сторонних скриптов, учётных записей,
публичного размещения и песочницы для недоверенного кода нет. Процесс агента не
получает seed или truth через протокол, однако одинаковые права ОС сами по себе
не изолируют произвольный Python-код. Будущее подключение судейских агентов должно
сопровождаться отдельной защитой файлов, сети, процессов и ресурсов.

Версия UI/API — 0.5.0. Версия линии генератора — 0.4.0, чтобы не менять ID открытых
эпизодов. Приложенные данные обновлены с дополнением публичной политики округления.
