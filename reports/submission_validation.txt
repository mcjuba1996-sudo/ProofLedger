ProofLedger Live 0.6.2 · Проверка комплекта к сдаче, 22 ноября 2026 года

Интерфейс жюри
Проверялись generate_episode, make_env и score_episode из judge_adapter.py.
Локальные тесты используют опубликованные условия C01–C20, R01–R20 и M01–M12.
В M04 лишняя отсутствующая ссылка дала 0 TP, 1 FP, 1 FN.
В M06 строка валюты в другом регистре дала 0 TP, 1 FP, 1 FN.
В M10 неоднозначная привязка двух выводов дала 2 TP, 0 FP, 0 FN.
Для M11 отдельно проверена привязка к исходным индексам при равенстве.
В C18 после реальной паузы 60,2 с на чистом эпизоде поздняя отправка дала
truncated=true и пустой итог. При первой отправке было 0 исследовательских шагов
и возврат 1,000. После двух запросов, включая ошибочный, возврат составил 0,996.
Значения совпали с score_episode. Политика в закрытом режиме получила 0.
Для политики в отдельном процессе WASI подтверждены чтение открытых счетов,
отправка двух документов по дублю, 1 TP и закрытая награда 0. Награда оценщика 0,998.

Данные и повторяемость
20 воспроизводимых эпизодов D01–D20, seed 16101–16120. Пять компаний чистые,
десять содержат по одной ошибке, пять содержат взаимодействующие ошибки.
Проверены происхождение изменений, арифметика по открытым данным, ссылки
и совпадение результатов при отправке эталонного ответа. На 20 парах файлов
проверены перестановка строк (5), замена ID (5) и оба преобразования (10).
Открытые 10 train- и 10 dev-эпизодов перегенерированы на версии 0.4.1.
Повторный экспорт воспроизвёл все 162 файла, включая 300 записей trajectories.jsonl.
На seed 51–150 у каждой пары дублей совпали контрагент, исходный номер, сроки,
валюта, сумма и позиции. В учёте были две отдельные проводки по обязательству.
На ранее проблемных seed 126, 128 и 138 в чистом D05 есть валютный счёт,
чья дата в документе вышла за границу периода. В часовом поясе компании
дата попала в период, а сумма проводки совпала с пересчётом по открытому курсу.

Диагностика четырёх политик
Одна матрица из 20 эпизодов для каждой политики, всего 80 прогонов. Средние по
эпизодам. Число шагов включает submit. P и R на чистом эпизоде при пустом
ответе равны нулю, F1 равен единице. Время указано от reset до терминального
step в миллисекундах и зависит от машины.

Воспроизведение
python -m proofledger
python -m proofledger.judge_benchmark

Результаты по интерфейсу, данным и четырём политикам выше получены на Windows x64.
Финальный Dockerfile компилирует поставляемый WASI-интерпретатор при сборке.
Команды для проверки первого запуска агента в новом Linux-контейнере с лимитом 45 секунд
docker build --network=none -t proofledger .
docker run --rm --network=none --cpus=2 --memory=4g proofledger python -m pytest -q tests/test_judge_policy.py
Команда для полного прогона локальных проверок
docker run --rm --network=none --cpus=2 --memory=4g proofledger
Закрытые фикстуры организаторов использует жюри.
